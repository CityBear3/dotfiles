# Rust review guidance

Use these references for Rust review, subject to repository guidance and the
approved design and scope:

- Read the [Rust implementation guidance](../../rust-implementation/SKILL.md)
  for idiomatic Rust, relevant Effective Rust items, module API placement,
  conditional re-exports, error contracts, spacing and documentation.
- When reviewing tests or their placement, read the
  [Rust testing guidance](../../test-driven-development/references/rust.md)
  and its shared test-contract reference.

Evaluate the actual implementation against those sources and its applicable
contract. Keep the rules in their canonical references and avoid demanding
unrelated layout migrations.
